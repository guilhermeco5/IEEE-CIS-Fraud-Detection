Como ler o resultado

O score é a saída do modelo. A faixa vem de dois limiares calculados no conjunto de teste: alto acima do limiar em que 1% das transações legítimas seriam bloqueadas, médio acima do de 5%.

Cada linha da tabela é uma feature e sua contribuição SHAP, em log-odds: positiva (vermelho) empurra o score para fraude, negativa (azul) para legítima. As cinco de maior peso aparecem.

Em modelos de árvore, uma feature ausente também é informação: por isso o valor "ausente" pode aparecer entre os fatores.
